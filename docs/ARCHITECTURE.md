# Architecture

## 5-stage conversation model

1. **Opening** — warm greeting, name/company confirmation, 10-minute consultation framing.
2. **Discovery** — growth drivers, current marketing channels, and six-month success metrics.
3. **Budget & Timeline** — budget range, desired start date, and decision-making authority.
4. **Objection Matrix** — price and existing-agency objections handled without loops or premature termination.
5. **Closing & Scheduling** — summarize requirements, move toward a strategy call, and terminate cleanly when appropriate.

## Control principles

- Ask one question at a time.
- Preserve information already supplied by the prospect.
- Handle objections where they arise instead of forcing a rigid stage reset.
- Use fallback behavior for vague or compound answers.
- Respect explicit declines immediately.
- Use `end_call` for the defined stop condition.

## Validation

The assessment completion report records all five simulation scenarios as passed.
